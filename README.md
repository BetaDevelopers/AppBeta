# Beta 3M - Gestor de Apuntes del Futuro 🚀

Bienvenido a **Beta 3M**, la herramienta definitiva para digitalizar y optimizar tus apuntes de clase con el poder de la Inteligencia Artificial.

## 🌟 Lo que hemos hecho
- [x] **Diseño "Blank Sheet" UX**: Interfaz minimalista centrada en el contenido (Papel Digital).
- [x] **Navegador de Archivos (Filesystem)**: Gestión de asignaturas y notas con sistema de arrastrar y soltar.
- [x] **Papelera de Reciclaje**: Recuperación de notas borradas accidentalmente.
- [x] **Búsqueda en Tiempo Real**: Encuentra cualquier nota o asignatura al instante.
- [x] **Exportación de Alta Fidelidad**: Exportación a PDF (fidelidad 1:1), Markdown y ZIP.
- [x] **Editor Enriquecido (Slate.js)**: Soporte para texto con formato y organización profesional.
- [x] **AI Assistant (Beta Optimizer)**: Refinado de texto, corrección gramatical y resúmenes automáticos.
- [x] **Escáner OCR Integrado**: Captura fotos de pizarras o cuadernos y conviértelas en texto editable.
- [x] **Insights en Tiempo Real**: Estadísticas de palabras, caracteres y tiempo de lectura.
- [x] **Modo Oscuro/Claro**: Adaptado para largos periodos de estudio.

## 💡 Ideas Sugeridas y Roadmap
- [ ] **Modo Libreta (Canvas Libre)**: Dibujo a mano alzada y anotaciones sobre el texto.
- [ ] **Sincronización en la Nube**: Guardado automático en tiempo real con cuentas de usuario.
- [ ] **Compartir Notas**: Generación de enlaces públicos para compartir apuntes.
- [ ] **Flashcards Automáticas**: Generar tarjetas de estudio a partir del contenido de la nota para repasar.
- [ ] **Voz a Texto**: Grabación de clases y transcripción automática.

## 🛠️ Tecnologías Usadas
- **React + Vite + TypeScript**
- **Zustand** (Estado Global)
- **Dexie.js** (IndexedDB para persisted storage)
- **Tailwind CSS + Framer Motion** (Diseño Premium)
- **Slate.js** (Editor de texto)
- **Tesseract.js** (OCR en el cliente)
